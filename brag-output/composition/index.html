pairwise judging Show the judge two answers and ask which is better — models compare more reliably than they score.
position bias Favoring the answer read first. VerdictAI runs (A,B) and (B,A) and counts the flips.
verbosity bias Preferring longer answers. Measured as the slope of score vs length, with a statistical test.
self-preference Grading its own model family’s style more kindly — those items are flagged for review.
04 · both orders

Cohen’s kappa — agreement beyond luck

kappa = (p_o − p_e) / (1 − p_e)
the worked example — pinned by a test
judge grades0011
human grades0111
agree 3/4 → p_o 0.75 luck → p_e 0.50 kappa = 0.5
0 · coin flip 0.5 · moderate 1 · perfect
why not raw agreement?Two graders flipping coins still agree a quarter of the time — kappa subtracts that luck.
Cohen’s kappa Agreement between two graders beyond luck. 0 ≈ a coin flip, 1 = perfect.
observed agreement (p_o) The raw fraction of items graded identically.
chance agreement (p_e) The agreement their scoring habits would produce by luck alone.
weighted kappa (QWK) Kappa with partial credit for ordered 0–5 scales — rating a 4 as a 5 is a small miss.
Spearman correlation Do the two graders rank items in the same order? −1 reversed, 0 none, 1 identical.
05 · agreement beyond luck

Curving the grades — isotonic regression

human score → judge score →
judge says 5, humans say 3.5 — saturation
PAV: walk left to right; whenever a block dips below its neighbor, pool them and average — until the staircase only climbs. The report prints agreement before → after, so overfitting shows itself.
one rulehigher must never become lower — no curve shape assumed
pinned fixturequery 2.5 → 3.75 (interpolated between fitted blocks)
the alternativePlatt scaling fits one rigid sigmoid — real judge error is messier
isotonic regression The best never-decreasing mapping from judge scores to human scores — a teacher curving marks, with no assumed shape.
PAV algorithm Pool-adjacent-violators: the O(n) way to compute that fit, implemented by hand in ~20 lines.
calibration curve Judge score in → human score out. Perfectly calibrated lies on the diagonal; this judge bulges.
Platt scaling The parametric alternative — one sigmoid, fine below ~50 labels, but it can only stretch and squeeze.

gate rule: CI clears the threshold and effect size (Cliff’s delta 1.0) clears the floor → regression → build fails, webhook alert fires. exit code — the number a program returns to the shell: 0 = pass, 1 = fail.
baseline The reference run you compare against — usually the last version you trusted.
snapshot One append-only record of a full run: model version, dataset hash, every per-item score.
paired delta Per item: baseline minus candidate. Pairing cancels item difficulty.
bootstrap confidence interval Resample the deltas 2,000 times; where the mean lands 95% of the time. Excludes 0 → unlikely luck.
effect size (Cliff’s delta) How big the change is: 1.0 means every item got worse. Guards against tiny “significant” shifts.
Wilcoxon signed-rank A rank-based paired test — the small-sample backup to the bootstrap.
