The lab also has a front door. The same harness runs behind FastAPI: submit an eval run, get an I-D back immediately, and poll until it succeeds. A webhook can call your systems when the run completes, signed with an HMAC so a fake all-clear cannot be injected. API keys are stored only as S H A 256 hashes. And every request may carry a correlation I-D, echoed on every response, so one run's story stays grep-able.
