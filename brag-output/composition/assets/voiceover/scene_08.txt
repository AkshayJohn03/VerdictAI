Now the alarm. Every run is snapshotted: an append-only record with the model version, the dataset hash, and every per-item score. When a new version arrives, Verdict A I pairs the runs item by item: baseline minus candidate score. Is the drop real, or luck? The bootstrap resamples those paired deltas two thousand times, and reports where the average drop lives ninety-five percent of the time. If that confidence interval excludes zero, luck is unlikely. The gate also demands a minimum effect size — Cliff's delta — because huge datasets make tiny shifts look significant. Only then: regression. Exit code one. The build fails, and a webhook fires. Noise passes in silence.
